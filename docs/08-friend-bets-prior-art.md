## Модель резолюции — сравнение

| Модель                        | Плюсы                                     | Минусы                             | Где у нас                 |
| ----------------------------- | ----------------------------------------- | ---------------------------------- | ------------------------- |
| Взаимное подтверждение        | мгновенно, 0 доверия третьим              | тупик при разногласии              | MVP, по умолчанию         |
| Судья-друг, выбранный заранее | гибко, работает для «субъективных» споров | сговор, судья пропал               | MVP, fallback + таймаут   |
| AI-судья по доказательствам   | масштабируется, вирально                  | ошибки, спорные кейсы              | 1.1, с апелляцией к судье |
| Council / арбитры со стейком  | без сговора                               | сложно, нужна ликвидность арбитров | Phase 2+                  |
| Оракул (спорт, цены)          | объективно, permissionless                | только для внешних событий         | Phase 3                   |

## Юридический ландшафт (не совет юриста)

- WagerLab/Betcha живут без денег — поэтому «легальны везде».
- Реальные деньги на **внешние** события = gambling почти везде → лицензии/гео.
- Реальные деньги на **собственные** действия = commitment device (Forfeit, Paywake, stickK живут годами).
- 1v1 без дома и без коэффициентов — ближе к «private wager between friends», в ряде юрисдикций не регулируется, в ряде — регулируется. Fee с банка ≠ vig, но платформа всё равно «facilitates».
- Практика: обязательства-first, лимит на спор, ToS с формулировками «commit / stake / claim», юрист до масштабирования.
